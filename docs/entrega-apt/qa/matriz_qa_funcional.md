## Referencias automatizadas

- Backend: `app/test_*.py`; catálogo sintético y cuentas: `app/test_qa_catalog.py`.
- Frontend: tres suites de Node incluidas en `npm test`; `npm run lint` ejecuta `tsc -b`; `npm run build` genera bundle.
- No hay suite E2E de navegador verificada en el repositorio. Las suites de proveedores R2/Webpay usan mocks/doubles; no equivalen a servicio externo.
- El registro por ejecución se mantiene en [REGISTRO_EJECUCION_VICENTE.md](REGISTRO_EJECUCION_VICENTE.md). Cada caso debe actualizarse con evidencia real, fecha, commit, navegador y ejecutor.
